## 🛠️ Featured Projects

### 🔹 [ALITA — Offline Multimodal RAG-Based AI Platform](https://github.com/KeertanaGupta) `Solo Project` · Feb 2026 – Present
Fully offline multimodal RAG system enabling semantic search across documents, codebases, images, and audio. Built an end-to-end retrieval pipeline with optimized chunking, embedding caching, and Top-K retrieval — integrating Ollama (local LLMs), FAISS vector search, and PostgreSQL into a privacy-first microservices architecture.

### 🔹 [StudySync — AI Study Group Matchmaking & Scheduler](https://github.com/KeertanaGupta) `Team Project` · Feb 2026 – Present
AI-powered matchmaking engine scoring compatibility across subject, goals, pace, and availability. Built a constraint-based scheduling engine for timezone-aware coordination, using semantic embeddings for explainable match recommendations.

### 🔹 [Mediprior — Smart Health Portal](https://github.com/KeertanaGupta) `Solo Project` · Aug 2025 – Nov 2025
Role-based healthcare platform (patient, doctor, admin) with JWT auth, EMR uploads, a vitals dashboard, and an AI mental-health chatbot. Real-time doctor–patient chat built with Django Channels & WebSockets.
